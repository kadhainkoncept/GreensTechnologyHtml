1. Enterprise Branch Network on Cisco

Platform: Cisco routers & switches (lab or simulator)

Design and build a multi-VLAN branch network from scratch. Configure inter-VLAN routing, single-area OSPF, DHCP and NAT for internet access, secure it with ACLs, port security and SSH, and add gateway redundancy with HSRP. Verify everything with show and debug commands.

Platform: Python, REST APIs & Ansible

Automate day-to-day network operations across routers and switches. Write Python scripts to retrieve and parse device configurations, interact with a REST API, monitor devices with SNMP and Syslog, and push configuration changes with Ansible playbooks.

Python REST API Ansible SNMP Syslog
Capstone Project 03

3. Secure Campus Wireless Network

Platform: Cisco Wireless LAN Controller & access points

Build a wireless network for a campus or office. Create WLANs on the controller, map each SSID to its own VLAN, secure the network with WPA2 PSK and WPA3, connect access points over trunk ports, and verify client connectivity, addressing with DHCP and protection with port security.

WLC WPA2 / WPA3 VLAN DHCP Port Security
Capstone Project 04

4. Site-to-Site VPN & Network Hardening

Platform: Cisco routers with IPsec (lab or simulator)

Connect two office networks over the internet with an IPsec site-to-site VPN. Harden every device with local passwords, AAA and SSH, filter traffic with extended ACLs, and protect the LAN with DHCP snooping and dynamic ARP inspection. Monitor the whole setup with Syslog and SNMP.

IPsec VPN AAA ACL SSH DHCP Snooping

Course FAQs

Everything you need to know about the CCNA programme, certification and how to get started.

Networking is the backbone of every IT system, and CCNA is an entry-level networking certification from Cisco. The course takes you from networking fundamentals to routing, switching, security and automation through hands-on labs, and prepares you for roles such as network engineer, network support engineer and NOC engineer.
You can start learning networking without prior experience. The syllabus begins with networking fundamentals. Cisco sets no formal prerequisites for the CCNA exam; contact Greens to confirm course admission requirements.
Both are Cisco certifications. CCST Networking (exam 100-150, US$125, 50 minutes) is an entry-level certificate for people just starting out. CCNA (exam 200-301, US$300, 120 minutes) is the associate-level credential employers ask for, covering routing, switching, security and automation in more depth.
The course covers all six official CCNA domains: network fundamentals, network access, IP connectivity, IP services, security fundamentals, and automation and programmability. The topics come from the official Cisco CCNA exam blueprint.
The CCNA 200-301 exam costs US$300 and lasts 120 minutes. It is a single exam with no prerequisites, and the certification is valid for three years.
The course is built around practical exercises: hands-on practice with VLANs, routing, ACLs, NAT, VPNs and network automation, plus capstone projects such as an enterprise branch network and network automation with Python and Ansible.
Greens Technologies provides a course completion certificate after the training. This is separate from the official Cisco CCNA certification, which you earn by passing the CCNA 200-301 exam at a Pearson VUE test centre or online.
The Cisco CCNA certification is valid for three years. You can renew it by passing a qualifying exam or earning continuing education credits. After CCNA, the natural next step is the CCNP Enterprise certification (ENCOR 350-401 core exam, US$400, plus one concentration exam with a separate additional fee).
